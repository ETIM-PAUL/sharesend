# Clearinghouse

Pay-per-check risk agent for tokenized stock trades on BNB Chain. See BUILD_PLAN.md.

## Setup
1. `cp .env.example .env` and fill in values (never commit `.env`).
2. Create a Binance Web3 API key (desktop browser): https://web3.binance.com/en/dev-portal/project
3. Fund the testnet wallet with tBNB.
